# Spritz Lite: free one-page wedding website template

A single-file HTML wedding site: full-bleed retro colour bands, hand-drawn
squiggles that draw themselves in on scroll, and a countdown badge. No build
step. Open index.html and edit.

Live demo: https://spritz-lite.vercel.app

## Quick start

1. Edit the text directly in index.html: your names, date, venue, the order
   of the day, and the closing message.
2. Replace the photos in img/ with your own (keep the filenames, or update
   the src paths).
3. Set your wedding date in the countdown script at the bottom of the file.
   The countdown updates itself.
4. Update the `mailto:` links (RSVP button and footer email) to your own
   address.
5. Upload anywhere. Vercel, Netlify and GitHub Pages host it free.

## Want the full version?

The full Spritz theme adds the things this one can't do:

- A password gate styled as your invitation, keeping the site off search
  engines and away from casual strangers
- A full RSVP where each guest picks their own menu choices, posted to your
  inbox or a form endpoint
- The menu section, driven by the same file as the RSVP
- Travel details and FAQs sections
- Eased parallax on the lifted photos and four colour packs with a one-click
  switcher
- Five-file JSON editing, no HTML required, plus a CMS-ready data layer
